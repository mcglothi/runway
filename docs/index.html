Install
Get Runway

The clean install path today is cloning the repo and building for your platform. Direct GitHub downloads and a Homebrew cask are planned, but they are not published yet.

Available now: source build Planned: GitHub Releases Planned: Homebrew cask
Build a local macOS app bundle
git clone https://github.com/mcglothi/runway.git cd runway npm install npm run build:mac
Builds a local DMG for Apple Silicon or Intel, depending on the Mac you build on.
Homebrew will be the cleanest macOS install once release artifacts exist. Until then, brew would just be wrapping a missing download.
Build a local Windows installer
git clone https://github.com/mcglothi/runway.git cd runway npm install npm run build:win
Builds a local NSIS installer for Windows.
Published Windows installers will land through GitHub Releases once the release pipeline has shipped its first tagged build.
Build local Linux packages
git clone https://github.com/mcglothi/runway.git cd runway npm install npm run build:linux
Builds a local AppImage and Debian package.
If you just want to try Runway today, this is the fastest Linux path while packaged downloads are still pending.
Build the current platform package
git clone https://github.com/mcglothi/runway.git cd runway npm install npm run build:electron
Requires Node.js 20+
